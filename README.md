# Urban Flood Digital Twin

An AI-based Urban Flood Digital Twin for Ballari City, Karnataka.

## Project Goal

The system predicts urban flood risk using environmental and geographical data,
visualizes risk on an interactive GIS map, creates a dynamic digital representation
of the urban area, and supports what-if flood scenario simulation.

## Core Modules

1. Data Collection & Processing
2. AI Flood Prediction
3. GIS Risk Mapping
4. Urban Digital Twin
5. Scenario Simulation & Explainable AI
6. Emergency Decision Support

## Technology Stack

- Frontend: React
- Backend: FastAPI
- AI/ML: Python, Scikit-learn, XGBoost
- GIS: GeoPandas, Rasterio, Leaflet
- Database: PostgreSQL + PostGIS
- Explainable AI: SHAP

## Study Area

Ballari Urban Area, Karnataka, India
